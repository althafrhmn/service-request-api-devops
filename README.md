# Service Request Management API

A DevOps portfolio project focused on building, testing, containerizing, securing, and deploying a REST API.

## Planned Technology Stack

- Python and FastAPI
- Git and GitHub
- pytest
- GitHub Actions
- Docker
- GitHub Container Registry (GHCR)
- Trivy
- Kubernetes
- Prometheus and Grafana

## Project Objectives

- Develop a REST API for managing service requests.
- Automate application testing using GitHub Actions.
- Containerize the application with Docker.
- Scan container images for vulnerabilities.
- Deploy the application to Kubernetes.
- Implement monitoring and health checks.
